## 言葉づかいのルール（この回）

- **シェアは「何の」「何年の」「誰の数字か」を添える**。採掘は約69%（USGS、2025年推計）、精製は約85%（IEA、2025年。2024年は91%）。2009年の「97%」は鉱山生産（USGS・GAO）。磁石は2010年に75%（GAO）。
- **2010年の対日停止は「禁輸」と断定しない**。日本の商社・メーカーは「日本向けだけが止まった」と訴え、中国商務部は「そのようなことはない」と否定。中国側は大臣に「密輸対策で検査を強化した」と説明。商社関係者には「年間の輸出枠を9月末で使い切る見込みだった」という別の説明も。漁船事件との因果は地の文で断定しない。
- **WTO（DS433）は2010年の対日停止を裁いたものではない**。争点は輸出税・輸出枠。中国の主張（資源保全・環境保護）も併記。
- **鄧小平の「中東に石油、中国にレアアース」**は「語ったと伝えられる」。公式の南巡講話記録（『鄧小平文選』第3巻）には出てこない。
- **マウンテンパスの停止理由は二つ**: 中国の安値と、排水パイプラインの漏れなどの環境・規制問題。
- **マグネクエンチ**は「米投資会社と中国の国有系企業2社のグループ」に売られた。「技術を盗まれた」とは言わない。
- **2026年の対日措置は「措置」と「結果」を分ける**。1月6日の措置は、日本の軍事ユーザー・軍事用途・軍事力向上に寄与する用途への両用品目の輸出禁止で、レアアースの名指しはない。結果として、ジスプロシウム・テルビウムの対日輸出は中国の統計でほぼゼロになった。リストは「輸出禁止」40団体と「審査を厳しくする注視」40社で別物。
- **高市首相の答弁は本人の言葉で**（「戦艦を使って、そして武力の行使も伴うものであれば…存立危機事態になり得るケース」）。同じ答弁の「即これを存立危機事態だと認定して…武力行使を行うということではない」も添える。中国側の評価は中国外交部・商務部を主語に。「報復」と地の文で言わない。
- **日本の工場が2026年の対日措置で止まった、とは言わない**（一次情報・大手報道なし）。2025年のスズキの停止は「関係者の話」として（スズキは「部品の供給不足」とだけ説明）。
- **MP マテリアルズは「米国で唯一の大規模なレアアース専用鉱山」**。国防総省との契約は「最低価格の保証」（1kg 110ドル、10年）。
- **南鳥島の数字は「資源量の推定」**で、埋蔵量ではない。水深は JAMSTEC の5,569m（揚泥管の長さ）。「世界初」は JAMSTEC の説明として。54%は「中重レアアース」。
- **価格は品目・場所・時点を添える**。「欧州の酸化ジスプロシウムが中国国内の約16倍（2026年9月、Benchmark）」。
- F-35 の「417kg」、2011年の瞬間最高値、マウンテンパス落札額「2,050万ドル」は使わない（未確認・疑義あり）。

## 台本で使う数字

| 事実 | 値 | 出典 |
| --- | --- | --- |
| レアではない | 17元素。セリウムは地殻で銅や鉛より多い。最も少ないツリウム・ルテチウムでも金の約200倍。「レア」なのは採算の合う濃さで集まる場所 | USGS FS087・SIR |
| 分けにくい | 化学的な性質がほとんど同じ。多段の溶媒抽出が必要 | EPA、Science News |
| 発見 | 1787年 イッテルビー村（ストックホルムの北東約20km）で重い黒い石。1794年 ガドリンがイットリウム。村の名から4元素 | Marshall |
| 最初の用途 | 1891年 ガスマントル、1903年 ライター石（セリウムと鉄）。いまもトライバッハで製造 | Austria-Forum、オーストリア特許庁 |
| マウンテンパス | 1949年 ウラン探しのガイガーカウンターが反応。品位8〜12%。1952年 採掘開始 | USGS SIR・FS087 |
| カラーテレビ | 赤はユウロピウム。米国生産 1964年256t→1966年12,200t。1966年に世界最大の供給源 | USGS FS087・DS140 |
| 米国の天下 | 1974年 米国19,900t／世界25,600t＝約78%（計算、最高） | USGS DS140 |
| 中国の鉱床 | 1927年 バヤンオボーの鉄鉱床を発見、1935年 レアアースを確認。鉄のついでに掘れる世界最大の鉱床 | 地質調査所1988、USGS |
| 分離技術 | 1970年代初めの中国はライター石用の混合金属まで。1972年 徐光憲が軍の任務、米鉱山局が「役に立たない」と機密解除した方式を出発点に、1974年 純度99.9%。特許を取らず国内に広がる | 徐光憲インタビュー（2014） |
| ネオジム磁石 | 1978年 佐川眞人氏が着想、富士通で「もっと富士通らしい研究を」。1982年 住友特殊金属で発見「3人とも飛び上がって喜びました」。GM のクロート氏も同年。特許の優先日は13日差。サマリウムコバルト磁石の約2倍。1gで約1kgの鉄を持ち上げる | JST、IMR、本田賞、特許 |
| 埋蔵量の公表 | 1983年 中国の公表で世界の埋蔵量が約6倍。1987年の日本の論文「もはや希少ではない」 | 地質調査所1988、Akashi 1987 |
| 逆転 | USGS の統計で1992年に中国が米国を上回る | USGS MYB 1992 |
| 安値 | 1990〜2008年 輸出は約10倍、平均輸出価格は約60%に（中国側の記事）。中国の白書（2012）は環境破壊と「価格は価値を反映していなかった」と認める | 米下院公聴会資料、白書 |
| 米国の撤退 | 1998年 マウンテンパスが分離停止（排水漏れが主因）、2002年 採掘終了。1995年 GM がマグネクエンチを7,000万ドルで売却、2003年までにインディアナの工場を閉じ設備は中国へ。2010年 米国のネオジム磁石生産ゼロ | S-1/A、GAO、In These Times |
