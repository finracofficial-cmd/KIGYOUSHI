# 台本スタイルガイド（栄枯盛衰ファイル）

参考チャンネル「消滅図鑑」の台本（`references/*/TRANSCRIPT.md`）から、**型**だけを抜き出したもの。
文章・言い回し・題材そのものは写さない。毎回、調べた事実から新しく書く。

> 現在の分析対象: 三洋電機（24.7分）。追加の参考動画を読み込んだら更新する。

## 数字で見る型（三洋回の実測）

| 項目 | 値 |
| --- | --- |
| ナレーション | 約6,700字 / 24.7分（毎分約270字） |
| 文の数 | 約130文。中央値34字（短い文21字〜長い文52字） |
| 構成 | つかみ約75秒 → タイトル → 5章（各3〜5分）→ 結び → 参考資料ロール |
| 絵 | 約33枚。1枚40秒前後 |

## 全体の流れ

1. **つかみ（60〜90秒、タイトル帯なし）**
   - 日常の具体物を並べて始める（「洗濯機、冷蔵庫、テレビ、エアコン。」のような名詞の列挙）。
   - 全盛期の数字を1〜2個（売上高・従業員数・シェア・店舗数）。
   - 名前を明かす短い一文（「〇〇です。」）。
   - 視聴者が覚えている製品・店・CMを3つほど挙げて懐かしさを起こす。
   - 「しかし、その〇〇は姿を消します。」で落とす。
   - **逆説**を置く（「倒産したわけではありません。」「世界一だったにもかかわらず」）。
   - 「なぜ〜のか。」を2回重ねて問いを立てる。
   - **このチャンネル自身の枠の一文**で終える（結びで同じ形に戻る）。
     参考チャンネルの決め台詞「これは、かつて確かに存在した〜の記録です。」は**使わない**。
     栄枯盛衰ファイルの枠: 「今回ひもとくのは、〇〇の栄枯盛衰です。」
2. **章（5つ前後、時系列）**
   - 1章: 創業と最初の成功。創業者・社名の由来・最初の商品・ヒットの理由（価格・技術・売り方）。
   - 2章: 拡大と全盛。多角化、象徴的な製品、ロゴや看板の誕生。章の終わりで「別の問題も積み重なっていきます」と影を差す。
   - 3章: 転機と危機。外部環境（技術変化・価格競争・災害・金融危機）と内部要因（投資・多角化）を**複数**挙げる。赤字や数字は年度つきで。
   - 4章: 再建・買収・統合の駆け引き。関係者それぞれの事情（買う側の狙い、売る側の事情、株主の事情）を並べる。
   - 5章: 名前が消える瞬間と、その後に残ったもの（ブランド・技術・人・海外での復活・最近のニュース）。
   - **章の最後の一文は次の章への引き**にする（「その資金を受け入れることが、後に〜大きな分岐点になります。」「それでも、この年。」）。
   - 章タイトルは答えではなく問いや場面にする（「〇〇が欲しかったもの」「日本から〇〇が消えても」）。
3. **結び（1〜2分）**
   - 「会社は〜では存在していません。それでも、〇〇があり、△△があり、□□で働いた人たちが作った会社がある。」のように、残ったものを並べる。
   - 最後は冒頭の枠に戻る: 「〇〇の栄枯盛衰。そのファイルを、ここで閉じます。」

## 文のリズム

- 基本は「です・ます」の説明調。歴史の出来事は**現在形で語ってよい**（「創業します」「発売されます」）。
- 短文の三連打で畳みかける: 「しかも汚れがよく落ちる。消費電力も少ない。場所を取りにくい。」
- 対比の繰り返し: 「Aには洗濯機がある。Bにも洗濯機がある。」
- 体言止めで場面を切る: 「リーマン・ショックです。」「松下電器産業。」
- 日付を頭に置いた事実文: 「2008年11月7日、〇〇と△△は〜と発表しました。」
- 「つまり、この買収は〜という話ではありませんでした。」で単純な見方を否定し、構造を説明する。
- 経営者の発言は「〜と説明しています」「〜との認識を示しました」と出典のある間接話法で。
- 1つの犯人を作らない。「〜だけが原因ではありません」で要因を重ねる。
- 感情語は控えめ。煽りではなく、事実の並べ方で驚かせる。

## 字幕との関係

- `lines` の1要素が字幕1枚。1〜2文、64字以内。短い文は前後とまとめてよい（2文で1枚）。
- 体言止めや短い問いは1文で1枚にして間を作る。

## 書き終えたら（チェックリスト）

- [ ] つかみに「逆説」と「なぜ」の問いがある。「今回ひもとくのは〜」で枠を作り、結びの「ファイルを、ここで閉じます」で戻っている。
- [ ] 参考チャンネルの決め台詞や特徴的な言い回しをそのまま使っていない。
- [ ] 各章の最後が次の章への引きになっている。
- [ ] 数字・年月・人名・社名がすべて research.md の出典つきの事実と一致している。
- [ ] 要因が1つに偏っていない。関係者それぞれの事情が書かれている。
- [ ] 現在につながる話（残ったもの・最近のニュース）がある。
- [ ] 6,000〜7,000字。章ごとの長さに大きな偏りがない。
- [ ] 数字・英字・読みにくい固有名詞に読みがついている（`[表示|よみ]` / `readings`）。
