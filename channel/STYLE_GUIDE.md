# 台本スタイルガイド（栄枯盛衰ファイル）

参考チャンネル「消滅図鑑」の4本（三洋電機・オンキヨー・船場吉兆・ダイエー）の台本を文字起こしして分析し、
**型**だけを抜き出したもの。文章・言い回し・決め台詞・題材そのものは写さない。毎回、調べた事実から新しく書く。
分析の元データはローカルの `references/*/TRANSCRIPT.md`（公開リポジトリには入れない）。

**このチャンネルの目標:** 20〜25分、ナレーション6,000〜7,000字、文の中央値25〜35字、数字は毎分2つ前後。

## 1. つかみ（60〜110秒、タイトル帯なし）

題材に合う型を1つ選ぶ。毎回同じ型にしない。

| 型 | 流れ | 向く題材 |
| --- | --- | --- |
| A. 懐かしさ＋逆説 | 日常の具体物を並べる → 全盛期の数字を2〜3段で積む（「1972年に〜、1980年に〜」） → 名前と、視聴者が覚えている製品・店・CM → 「しかし、その〇〇は姿を消します」 → **逆説**（「倒産したわけではありません」「今も会社は存在します」） | 誰もが知るブランド・業態 |
| B. 感覚の描写＋結末を先に | 製品を使っていた時の感覚・情景を描く → 「〜したい。そんな願いに応えてきたのが〇〇でした」 → 「ところが、〇年〇月〇日、〜」と結末を先に言う → 数字を体言止め1つ（「負債総額はおよそ〇億円。」） | 趣味性の高い製品、技術ブランド |
| C. 名場面から入る | 日付・場所・場面から始める（有名な会見・事件・発表） → 人物を短い2文で明かす → 「覚えている人は多いでしょう。では、その中身は？」と記憶のずれを突く → 結末を先に | 事件・不祥事・有名な一場面がある題材 |

型に関係なく、つかみの最後は必ず次の順にする:
1. 「なぜ〜のか。」の問いを1〜3つ（3つ目に「その後どうなったのか」を置くと、終盤の現在パートを予告できる）。
2. 必要なら目的の一文（「今回は、〜に至る経緯と、その後に残されたものをたどります。」）。
3. **このチャンネルの枠の一文**: 「今回ひもとくのは、〇〇の栄枯盛衰です。」
   参考チャンネルの決め台詞「これは、かつて確かに存在した〜の記録です。」は**使わない**。

## 2. 章（5〜6章）

- 基本は時系列。各章は3〜10分。長さは揃えなくてよい（いちばん大きな転落の章が長くなるのは自然）。
- 章の役割の例（題材に合わせて組み替える）:
  1. 原点 — 創業、または創業者の**原体験**（戦争・貧しさ・修業時代）。最初の商品・店。成功の理由（価格・技術・売り方）。
  2. 全盛 — 拡大、象徴的な製品、業界での立ち位置（競合の列挙、「〇〇戦争」）、ロゴや看板。章の終わりで影を差す。
  3. 転機 — 外部環境（技術の変化、価格競争、災害、金融危機、規制）と内部要因（投資、多角化、組織）を**複数**重ねる。
  4. **「なぜ」の分析章**（任意）— 時系列から少し離れ、通説（「バブルのせい」）を認めたうえで「それだけではありません」と要因を3つほど並べる。
  5. 決着 — 再建・買収・破産・廃業。関係者それぞれの事情（買う側の狙い、売る側の事情、株主・取引先・従業員）。
  6. その後 — 名前が消えた後に残ったもの（ブランド、技術、人、新しい会社、海外での復活、最近のニュース）。
- **章の入り方**: 前の章の最後の事実を一文で言い直してから始める（「〇年、△△の一員となった〇〇は〜」）。
- **章の終わり方**: 次の章への引き（「〜が、後に〇〇の大きな分岐点になります。」「そして、あの会見が開かれるのです。」）か、転落の章では総括の一文。
- **章タイトル**は答えではなく、問い・場面・人物の言葉にする（「〇〇が欲しかったもの」「価格を決めるのは誰か」、創業者の短い言葉の引用）。

## 3. 結び（2〜4分）

- 現在の姿（譲渡先・社名変更・新製品・解体・復活）を具体的な年と事実で。
- 「会社は〜では存在していません。それでも、〇〇があり、△△があり、□□で働いた人たちがいる。」と残ったものを並べる。
- 原点の場面・言葉・モチーフ（創業者の願い、冒頭の情景）にもう一度触れる。
- つかみの逆説をもう一度言う（「会社も、店も、看板もある。それでも、あの〇〇はもうない。」）。
- 教訓の言い切りは1文だけ（「その時代の正解は、永遠には続かない」のような一般化）。説教にしない。
- 最後に枠へ戻る: 「〇〇の栄枯盛衰。そのファイルを、ここで閉じます。」（主題を一言添えて変化させてよい）

## 4. 「なぜ」の答え方

- **単一の犯人を作らない**。「〜だけが原因ではありません」「一言では片付けられません」で要因を重ねる。
- 外部要因と内部要因を両方書く。内部要因は「成功の仕組みが逆回転した」構図で見せると伝わりやすい
  （「増やせば→売上が増え→さらに強くなる」を前半で描き、後半で「エンジンが逆向きに回り始めます」）。
- 経営判断には、その時点の合理性を添える（「この判断には理由がありました」）。後知恵で断罪しない。
- 「〜わけではありません」で誤解を先回りして解く（「上場廃止は、すぐに倒産という意味ではありません」）。
- 判定は当事者自身の言葉や公式文書に語らせる。ナレーターの評価は控えめに、視点を明示して1〜2か所だけ。

### 不祥事・実在の人物を扱うときの必須ルール

- 責任の記述は**出典を主語**にする（調査報告書・改善報告書・判決・会見・行政処分・本人の証言）。
- 伝聞には「〜といいます」「〜とされています」「〜という話も残っています」を付け、確かさで言い分ける。
- 会社・当事者側の言い分も必ず並べる。当時の法律でどう扱われたかを正確に書く。
- 嘲笑・あだ名いじりをしない。あだ名は「〜と呼ばれるようになりました」と呼んだ側の言葉として紹介するだけ。
- 再起した人の話には、本人の責任や関与も併記する。
- 存命の個人を、確かな出典なしに悪く書かない。

## 5. 文のテクニック

基本は「です・ます」の説明調。歴史の出来事は現在形で語ってよい（「創業します」「発売されます」）。

| 技 | 例（型の説明。実際の台本は毎回新しく書く） |
| --- | --- |
| 短文の三連打 | 「汚れがよく落ちる。電気代も安い。場所も取らない。」 |
| 対比の繰り返し | 「Aには洗濯機がある。Bにも洗濯機がある。」 |
| 体言止め・年だけの一文 | 「リーマン・ショックです。」「そして、2015年。」 |
| 日付を頭に置く事実文 | 「2008年11月7日、〇〇は〜と発表しました。」 |
| 「つまり、〜という話ではありませんでした」 | 単純な見方を否定し、構造を示す |
| 用語の解説 | 「債務超過とは、〜の状態のことです。」（専門用語は必ず一度説明する） |
| 連鎖文 | 「部品が買えない。買えなければ作れない。作れなければ売れない。」 |
| 章の途中の自問自答 | 「では、なぜ〜だったのでしょうか。」→すぐ答える |
| 「実は」「ただし」 | 意外な事実の提示、前提のひっくり返し |
| 持ち上げた直後の留保 | 「絶頂でした。少なくとも、外からは。」 |
| 通説→否定 | 「道楽にも見えます。しかし、〜」 |
| 1つの具体物に寄る | 「例えば、〇〇。△gで□円。」 |
| 言い分を並べて崩す | 「〜と説明しました。しかし、〜」を1つずつ |
| 発言と結果の対比 | 「大丈夫だと語った、その2週間後。」 |
| 経過時間で距離を出す | 「あの会見から、およそ5か月。」 |
| 比喩・モチーフの持続 | 「帝国」「エンジン」など1つを最後まで使う |
| 主人公の性格を一文で | 「普通なら諦める。しかし、彼は〜」 |
| 直接引用（短く、独立した一文） | 「返ってきた言葉は、こうでした。」の後に置く。方言はそのまま |
| 内面の推測は控えめに | 「そう考えていたのでしょう。」 |
| 共感の一文は結びだけ | 「〜という人もいるかもしれません。」 |

感情語は控えめにする。煽らず、事実の並べ方で驚かせる。

## 6. 数字

- 毎分2つ前後。大半は年。日付まで言うのは、法的な出来事・会見・災害・死去など節目だけ。
- 金額には「約」「およそ」を付け、前後の比較で見せる（「644億円から、わずか89億円に」）。
- 題材によって数字の性格を変える。大企業なら売上・従業員・店舗数、事件なら価格・人数・期間など暮らしの大きさの数字。
- **差や倍率は自分で計算して確かめる**（参考動画にも計算違いがあった）。
- 赤字額・負債額を伏せて「巨額の」と言うのは、出典の数字が揺れているときだけ。

## 7. 字幕・絵との関係

- `lines` の1要素が字幕1枚。1〜2文、64字以内。体言止めや短い問いは1文で1枚にして間を作る。
- 絵1枚（block）は30〜60秒。場面・時代・場所が変わる文の頭で絵を替える。
