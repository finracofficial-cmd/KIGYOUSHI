# 題材の選び方（栄枯盛衰ファイル）

企業・ブランド・産業の「全盛と転落（と、その後）」を描く。会社だけでなく、業界・製品カテゴリ・
業態（例: ポケベル、レンタルビデオ店、写真フィルム）も対象にする。

## 選ぶ基準（点数をつけて上位を選ぶ）

| 基準 | 見るところ | 点 |
| --- | --- | --- |
| 知名度・懐かしさ | 30〜50代の日本人が名前・製品・CM・店舗を覚えているか | 0〜3 |
| 謎の強さ | 「倒産していないのに消えた」「世界一だったのに」「誰もが使っていたのに」など、一言で言える逆説があるか | 0〜3 |
| 落差 | 全盛期の数字（売上・シェア・店舗数・従業員数）と転落後の差が大きいか | 0〜2 |
| 資料の量 | 公式沿革・IR・報道・書籍で年月と数字が確かめられるか（20〜25分ぶん語れるか） | 0〜2 |
| 今につながる | 現在も残るブランド・技術・人、最近のニュース（復活・解体・売却）があるか | 0〜1 |
| 絵になる | 時代ごとの製品・店・工場・街並みを描けるか | 0〜1 |

7点以上を候補にする。同じ年に同じ業界が続かないように散らす。

## 避けるもの

- 参考チャンネル（消滅図鑑）がすでに扱った題材そのもの（下の一覧）。同じ業界の別の会社は可。
- 事件・事故の被害者や個人を中心に据える話、存命の個人への批判が中心になる話。
- 資料が少なく、推測で埋めることになる題材。

## 参考チャンネルが扱った題材（重複を避ける）

- 三洋電機（パナソニックによる買収とブランド消滅）
- オンキヨー（2022年の自己破産。名門オーディオメーカーの転落）
- 船場吉兆（2007年の食品偽装と「ささやき会見」、廃業）
- ダイエー（日本一のスーパー。イオン傘下への道）
